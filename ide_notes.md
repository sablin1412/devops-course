# Сравнение работы с Git в VS Code (IDE) и в терминале (CLI)

## 3 вещи, которые удобны в VS Code:
1. Наглядное визуальное отображение изменений (diff) в файлах с подсветкой добавленных и удалённых строк.
2. Быстрый просмотр истории изменений каждой строки кода и автора коммита через расширение GitLens (git blame).
3. Удобное разрешение конфликтов слияния (merge conflicts) в интерактивном визуальном редакторе.

## 1 вещь, которую удобнее делать в терминале:
1. Выполнение сложных операций управления историей (git rebase -i, cherry-pick, фильтрация логов) и работа на удалённых Linux-серверах по SSH, где нет графического интерфейса.
